PRT(Peer Review Template)
[O] 1. 주어진 문제를 해결하는 완성된 코드가 제출되었나요?
DeepLabV3 기반 Semantic Segmentation 모델을 활용하여 객체와 배경을 분리하는 과정을 구현하였습니다.
인물모드(아웃포커싱), 동물 사진 아웃포커싱, 크로마키 배경 전환 결과를 확인할 수 있었으며, 프로젝트에서 요구한 최종 결과물이 포함되어 있습니다.
또한 결과 이미지와 함께 문제점을 분석하고 개선 방안을 제시하여 프로젝트 목표를 충실히 수행하였습니다.

[O] 2. 전체 코드에서 가장 핵심적이거나 가장 복잡한 부분에 대한 설명이 잘 작성되었나요?
DeepLabV3 모델을 불러와 Segmentation Mask를 생성하고, 이를 활용하여 객체와 배경을 분리하는 핵심 과정이 단계별로 정리되어 있습니다.
특히 Mask 생성 후 배경 Blur 처리 및 크로마키 합성 과정이 코드 흐름에 맞게 작성되어 있어 전체적인 처리 과정을 이해하기 쉬웠습니다.
각 단계별 결과를 시각화하여 모델이 어떻게 동작하는지 확인할 수 있는 점도 좋았습니다.

[O] 3. 에러를 해결하거나 새로운 시도 및 추가 실험을 수행했나요?
Semantic Segmentation 과정에서 발생하는 경계 영역 오분류 문제를 직접 확인하고 분석하였습니다.
털, 귀, 발과 같은 세밀한 부분에서 마스크가 부정확하게 생성되는 문제를 발견하였으며, 이를 해결하기 위한 방법으로 Depth Estimation, Matting 등의 기술을 제안하였습니다.
단순히 결과를 생성하는 데 그치지 않고 모델의 한계를 분석하고 개선 방향을 고민한 점이 인상적이었습니다.

[O] 4. 회고를 잘 작성했나요?
Semantic Segmentation의 장점과 한계를 정리하였으며, 실제 카메라의 피사계 심도를 완벽하게 구현하기 어려운 이유를 설명하였습니다.
또한 향후 적용 가능한 기술과 개선 방향을 함께 제시하여 프로젝트 수행 과정에서 얻은 학습 내용을 잘 정리하였습니다.
결과 분석과 개선 아이디어가 포함되어 있어 프로젝트에 대한 이해도를 확인할 수 있었습니다.

[O] 5. 코드가 간결하고 효율적인가요?
이미지 로드 → 모델 추론 → Mask 생성 → 배경 처리 → 결과 출력의 흐름이 논리적으로 구성되어 있습니다.
불필요하게 복잡한 구조 없이 단계별로 구현되어 있어 가독성이 좋습니다.
결과 확인을 위한 시각화 코드도 적절하게 포함되어 있어 전체 실행 과정을 쉽게 따라갈 수 있습니다.

회고

이번 프로젝트는 DeepLabV3를 활용하여 Semantic Segmentation을 수행하고, 이를 기반으로 인물모드와 크로마키 기능을 구현한 점이 인상적이었습니다. 특히 단순히 결과 이미지를 생성하는 데서 끝나지 않고, Segmentation Mask의 한계를 직접 분석하고 개선 방안을 제시한 점이 좋았습니다.

프로젝트를 살펴보면서 Semantic Segmentation이 객체를 구분하는 데 효과적이지만, 머리카락이나 동물의 털과 같은 경계 영역에서는 여전히 한계가 있다는 점을 다시 확인할 수 있었습니다. 또한 실제 스마트폰의 인물모드 기능이 단순한 Segmentation뿐 아니라 Depth 정보와 다양한 후처리 기술을 함께 사용한다는 점도 이해할 수 있었습니다.

전반적으로 프로젝트의 목표를 충실히 달성하였으며, 결과 분석과 개선 아이디어까지 포함되어 있어 학습 과정이 잘 드러난 프로젝트라고 생각합니다.
